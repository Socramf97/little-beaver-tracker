Used to hold code for speech-to-text logic. Placeholder to avoid empty folder.

Tiers for voice activation

1. Push-to-talk
   - iOS: Mic Button -> Speech-to-text
   - Android: Same
2. Hail word, app open
   - iOS: Porcupine wake word ("Hey Beaver)
   - Android: Same
3. App closed/background
   - iOS: Siri app shortcut opens the app then starts listening
   - Porcupine in foreground service, with a mic notification
