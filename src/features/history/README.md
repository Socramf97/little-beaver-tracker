# History Feature

The History feature displays feeding, diaper, and measurement events for the currently selected baby.

## Capabilities

- View event history
- Filter history by active baby
- Edit feeding events
- Edit diaper events
- Edit measurement events
- Delete events with confirmation
- Display events in chronological order

## Data Sources

- Feeding events
- Diaper events
- Measurement records

## Main Files

- history.tsx
- services/database/history.ts
